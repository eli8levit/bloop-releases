The first release of Bloop: a menu-bar translator for macOS. Select text in any app, double-tap
the modifier key you chose, and the translation appears in a popover beside the selection — no
window, no copy and paste, and the app you were in stays in front.

- Apple's on-device translation for the languages it covers, so the text you select never leaves
  your Mac. Language packs download once, on first use.
- Google Translate as an optional fallback for the 100+ languages Apple does not cover yet,
  including Hebrew. Off by default; results carry a "via Google" tag.
- A compose field inside the popover for writing back in the other language.
- Pinned languages, with `⇥` to step between them and `⌥⇥` to change the source.
- History of everything you have translated, in a panel on `⌥⌘Y` that never takes focus from the
  app you are writing in.
- Light, dark, or the system appearance; an animated fish that respects Reduce Motion.
- One permission — Accessibility, so Bloop can read the selection — and nothing else.

**Requires macOS 26.** Signed with a Developer ID and notarized by Apple, so it opens normally.

Bloop is a one-time purchase. One licence covers three Macs; paste the key from your receipt in
Settings or in the first-run window.
